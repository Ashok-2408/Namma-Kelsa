# Namma-Kelsa

Namma-Kelsa is a premium, animation-rich local service booking application designed to connect skilled experts (plumbers, electricians, carpenters, etc.) with users in their local community.

## 🚀 Features

- **Expert Search**: Find verified professionals in your city.
- **Real-time Booking**: Book services instantly and track your service history.
- **Premium UI**: Modern, fluid animations with Material 3 design.
- **Dual Role Support**: Register as a User or an Expert.
- **Multilingual**: Support for English and Kannada.
- **Dark Mode**: Seamless theme switching for better user experience.

## 🛠️ Tech Stack

- **UI**: Jetpack Compose (Material 3)
- **Architecture**: MVVM with Clean Architecture principles
- **Dependency Injection**: Hilt
- **State Management**: StateFlow & Preferences DataStore
- **Backend**: Firebase Auth, Firestore, and Storage
- **Image Loading**: Coil
